# sanchoris

A hosted service that runs predictable skills inside AI coding agent sessions. A skill shows its flow, its limits and its track record before it runs; the engine runs the fixed steps and hands the agent only the steps that need it. You start a session and talk to the agent; a trigger only performs that same start for you on a GitHub event or a schedule. The agent runs on your own Claude and Codex subscriptions.

This repository is being built from scratch. The previous implementation is kept at [sancode-org/sanchoris-old](https://github.com/sancode-org/sanchoris-old) as a reference.

See `AGENTS.md` for the conventions and the design documents.
