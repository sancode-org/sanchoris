# sanchoris

A hosted service where an issue on GitHub, a chat message or a schedule starts an AI coding agent session in the cloud, and the task is not complete until the required skills (predictable flows that the engine runs) succeed. The agent runs on the customer's own Claude and Codex subscriptions.

This repository is being built from scratch. The previous implementation is kept at [sancode-org/sanchoris-old](https://github.com/sancode-org/sanchoris-old) as a reference.

See `AGENTS.md` for the conventions and the design documents.
